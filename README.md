# Credit Card Fraud Analysis | Python & Power BI

## Project Overview
This project focuses on analyzing credit card transactions to identify fraudulent transaction patterns and compare fraudulent transactions with legitimate transactions. Python is used for data analysis and feature engineering, while Power BI is used to visualize insights through an interactive dashboard.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Microsoft Power BI

## Project Workflow
1. Explored the transaction dataset using Python.
2. Performed data analysis and investigated fraud patterns.
3. Compared fraudulent and legitimate transactions.
4. Analyzed transaction features to identify useful patterns.
5. Prepared the processed dataset for Power BI.
6. Developed a dashboard to visualize fraud-related insights.

## Key Analysis Areas
- Fraudulent vs. legitimate transactions
- Transaction feature comparisons
- Fraud pattern identification
- Transaction data visualization

## Key Learnings
- Data cleaning and exploratory data analysis
- Data manipulation using Pandas
- Feature analysis using Python
- Data visualization and dashboard development using Power BI
- Communicating analytical findings visually

## Conclusion
This project demonstrates the use of Python and Power BI to explore transaction data, investigate potential fraud patterns, and present findings through data visualization.
